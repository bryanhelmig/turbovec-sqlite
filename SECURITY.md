# Security

Security fixes are made against the latest release. Older 0.x releases may not
receive patches.

Report a suspected vulnerability through
[GitHub private vulnerability reporting](https://github.com/bryanhelmig/turbovec-sqlite/security/advisories/new).
Do not open a public issue for an undisclosed vulnerability.

Include the extension version, SQLite version, host platform, impact, and a
minimal reproducer when possible. Never include production credentials or
private data.
